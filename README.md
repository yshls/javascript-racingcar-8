# javascript-racingcar-precourse

# 구현할 기능 목록

### 1. 입력 및 준비

- [x] 경주할 자동차 이름을 입력받는다.
- [x] 입력받은 이름을 쉼표(`,`)를 기준으로 분리한다.
- [x] 분리된 각 이름이 5자 이하인지 검증한다.
- [x] 시도할 횟수를 입력받는다.
- [x] 각 자동차의 이름과 출력을 위한 전진 상태를 관리할 준비를 한다.

---

### 2. 경주 실행

- [x] 입력받은 횟수만큼 다음 과정을 반복한다:
  - [x] 각 자동차마다 0에서 9 사이의 무작위 값을 구한다.
  - [x] 무작위 값이 4 이상일 경우, 해당 자동차를 전진시킨다.
  - [x] 자동차별 실행 결과를 출력한다.

---

### 3. 결과 발표

- [x] 경주가 완료된 후, 최종 우승자를 결정한다.
- [x] 최종 우승자를 형식에 맞게 출력한다.
  - 단독 우승 예: `최종 우승자 : pobi`
  - 공동 우승 예: `최종 우승자 : pobi, jun`

---

### 4. 예외 처리

- [x] 사용자가 잘못된 값을 입력할 경우, `[ERROR]`로 시작하는 메시지를 발생시키고 애플리케이션을 종료한다.
  - [x]자동차 이름은 5자 이상이면 에러 발생
  - [x] 횟수 입력할때 문자열, 음수, 0, 정수가 아닐 경우 에러 발생
